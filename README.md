# Renessans Startup Academy — Interactive Pitch Deck

Professional, interactive presentation built for Smart Boards (touchscreen & 16:9 displays) and investor pitches.

## 🚀 Overview
The team analyzed 5 foundational problem-solution startup ideas across Uzbekistan's key sectors:
1. **UniBite** (FoodTech) — Online pre-ordering system to eliminate long queues in university canteens.
2. **Locally** (Marketplace) — Hyperlocal e-commerce & escrow platform for housewives and craftspeople.
3. **AgroSmart** (IoT / AgriTech) — Smart irrigation and soil moisture monitoring to prevent 40%+ water waste.
4. **GreenReward** (EcoTech) — AI waste scanning & gamified recycling rewards platform.
5. **Tracker OS** (Flagship Hero Startup) — 3-in-1 gamified productivity, habit tracking, and focus OS.

## 🛠 Tech Stack & Architecture
- **Monolithic Single-File UI**: Vanilla HTML5 + Tailwind CSS CDN + Lucide Icons + Vanilla JavaScript.
- **Display Compatibility**: 16:9 Smart Board native, responsive down to tablets and mobile.
- **Controls**: Touch swipe, keyboard shortcuts (`[←]` / `[→]`, `[F]` for fullscreen, `[1]-[0]` for slide jumping), and 700ms smooth wheel throttle.
- **Offline-Ready**: Local asset linking with zero external runtime dependencies for core images.
